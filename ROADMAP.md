# What I'm working on

None of this has a date. It ships when it works, and it shows up in [CHANGELOG.md](CHANGELOG.md) when it does.

**Next release (1.5.1)**
- Live TV: M3U and Xtream playlists, HDHomeRun tuners, a guide and recording
- Settings rewritten in plain words, with a hint under every one
- Private libraries that stay hidden until you enter a PIN
- Apps follow your server automatically when its address changes
- A signed Windows installer, once signing is sorted out

**After that**
- DLNA, so smart TVs and consoles can play from the server with no app
- A ready-made Docker image, and packages for NAS boxes
- Ratings and parental controls you can set up however you want, or leave off
- Tracking for missing media files, so a dropped drive doesn't wipe your library
- More apps: Fire TV, LG and Samsung TVs, desktop, and Apple devices
- The server on Mac

Want something that isn't here? Start a thread in [Discussions](../../discussions).
